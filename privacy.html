Privacy Policy

Last Updated: September 19, 2026

This Privacy Policy explains how [BOT NAME] ("the Bot", "we", "us", or "our") processes information when the Bot is used on Discord.

We aim to process only information reasonably necessary to operate, maintain, secure, and improve the Bot.

1. Information We May Process

Discord Account Information

  • Discord user ID.
  • Discord username or display name.
  • Discord avatar or related profile information when required by a feature.
  • Discord roles and permission information necessary to determine authorization.

Server Information

  • Discord server/guild ID.
  • Channel IDs.
  • Role IDs.
  • Message IDs.
  • Server configuration values required for Bot features.

Moderation Information

When moderation functionality is used, the Bot may process information necessary to perform or record the requested moderation action, such as the affected user, initiating user, action type, relevant Discord IDs, and associated date/time.

2. Message Content

Some Bot features may require message content to be received or processed through Discord's APIs. Where message content is processed, it is used only for the feature that requires it. We do not intentionally use message content for advertising or sell message content to third parties. Unless a specific feature explicitly requires storage, message content is not intended to be retained permanently merely because it was processed by the Bot.

If leveling, profile, or activity features are enabled, the Bot may process Discord user ID, server ID, message or interaction counts, XP, level, rank, and other statistics required to provide the feature. These values may be stored so progress can persist across restarts or sessions.

4. Notification and Role Features

If notification panels or self-role features are enabled, the Bot may process user ID, server ID, role ID, and button or interaction information to provide role-selection and notification functionality.

5. How We Use Information

  • Execute commands and interactions.
  • Perform moderation actions.
  • Check permissions and authorization.
  • Manage configured server roles and channels.
  • Provide notification features.
  • Maintain leveling or activity statistics.
  • Maintain server-specific configuration.
  • Diagnose technical problems and prevent abuse.
  • Maintain security and reliability.
  • Comply with applicable legal obligations.

6. Data Sharing

We do not sell or rent personal information collected through the Bot. Information may be processed by services necessary for operation, such as Discord and Discord APIs, hosting or infrastructure providers, and other technical providers necessary for operation or security. Information may also be disclosed where required by law or valid legal process.
